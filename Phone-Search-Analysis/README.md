# Phone Search Analysis Dashboard

## Project Overview
This project focuses on analyzing mobile phone data using Microsoft Excel to explore smartphone specifications, prices, brands, and market trends through an interactive dashboard.

The project aims to transform raw phone data into meaningful insights that help users compare mobile phones based on their features, prices, and technical specifications.

## Business Objectives
- Analyze smartphone prices across different brands.
- Compare phone specifications and features.
- Explore the relationship between phone prices and technical specifications.
- Identify pricing trends across different smartphone categories.
- Build an interactive dashboard for data exploration.

## Tools & Technologies
- Microsoft Excel
- Power Query
- Power Pivot
- Pivot Tables
- Pivot Charts
- Slicers
- Interactive Dashboard

## Data Preparation
- Cleaned product color, size, and style columns.
- Handled missing and inconsistent values.
- Removed unnecessary spaces using Trim.
- Corrected data types for numeric and categorical columns.
- Removed duplicate records.
- Prepared the dataset for analysis and visualization.

## Key Performance Indicators
- Total Products
- Average Original Price
- Total Sales Value
- Sales Volume
- Product Availability

## Analysis
The dashboard explores:
- Smartphone prices and sales volume.
- Product distribution by color, size, and style.
- Product availability and sales performance.
- Comparisons between different product categories.
- Patterns and trends in smartphone data.

## Dashboard Features
- KPI cards to summarize key metrics.
- Interactive charts for comparing products.
- Slicers to filter and explore the data.
- Pivot Tables and Pivot Charts for dynamic reporting.
